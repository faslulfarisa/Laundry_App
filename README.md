# 🧺 Laundry Management System

A full-stack web application built to streamline day-to-day operations for a laundry business — including order tracking, customer management, and automated billing.

## 🚀 Features

- **Order Tracking** – Create, update, and monitor laundry orders through different status stages
- **Customer Management** – Store and manage customer records and order history
- **Automated Billing** – Calculate bills automatically based on order details
- **Responsive UI** – Built with React.js for a clean, mobile-friendly experience

## 🛠️ Tech Stack

**Frontend:** React.js  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Architecture:** RESTful API
